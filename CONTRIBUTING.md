# Contributing

Thank you for looking. This repository is read-mostly: the devices are designed and built in one place, and changes
come back here from there.

- **Issues are welcome**: a bug, a device that misbehaves in Live or on Push 3, a question, an idea. Say which Live
  and Push OS versions, and what you did.
- **Pull requests by invitation**: open an issue first. If a change fits, you'll be asked for one.
